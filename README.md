## 核心能力

**嵌入式开发**  
`C / C++ / STM32`  
设备通信、控制逻辑与嵌入式应用开发。

---

**实时系统**  
`RTOS（实时操作系统） / 状态管理 / 任务调度`  
关注并发、事件、消息与长期可维护性。

---

**工具与应用**  
`Flutter（跨平台应用框架） / Docker（容器平台） / AI Agent（人工智能代理）`  
构建个人工具、自托管服务与辅助开发工作流。
