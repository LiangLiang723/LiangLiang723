# Linear 风格 GitHub 个人主页设计

## 1. 目标

将现有 Apple Editorial 2.0 主页重构为更接近 Linear 的极简产品界面风格，减少模板感、卡片堆叠和装饰竞争。

本次设计的核心目标：

- 支持明亮与深色主题自动切换。
- 只保留必要信息，页面重点清晰。
- 视觉接近 Linear：低对比背景、细边框、微弱网格、少量紫蓝光。
- 尽量使用 GitHub 原生文字排版，仅顶部横幅使用自制 SVG。
- 保留贡献贪吃蛇，但将它弱化为页面底部的数据延伸。

## 2. 页面范围

主页最终只保留以下五部分：

1. 身份介绍
2. 核心能力
3. 当前研究方向
4. 精简开发数据
5. 贪吃蛇贡献轨迹

明确删除：

- 精选项目模块
- 最近动态模块
- 技术徽章墙
- 多张自制内容卡片
- 高效时段卡片
- 大型页尾卡片
- Apple Editorial 2.0 的复杂 SVG 组件体系

## 3. 顶部横幅

顶部使用一组明暗主题 SVG：

- `assets/linear/hero-light.svg`
- `assets/linear/hero-dark.svg`

### 3.1 内容

横幅只展示：

- 小型账号名：`LiangLiang723`
- 主标题：`亮亮`
- 职位：`嵌入式软件工程师`
- 简介：`专注设备控制、RTOS 与可靠软件架构。`

### 3.2 视觉

明亮主题：

- 背景接近 `#F7F7F8`
- 主文字接近 `#171719`
- 辅助文字接近 `#6B6B70`
- 边框接近 `rgba(0,0,0,0.08)`

深色主题：

- 背景接近 `#0F1012`
- 主文字接近 `#F7F7F8`
- 辅助文字接近 `#96969D`
- 边框接近 `rgba(255,255,255,0.10)`

共同规则：

- 高度约 220–250 像素。
- 极淡网格，仅用于增加空间层次。
- 右侧保留一个低透明度紫蓝渐变光斑。
- 不使用胶囊标签、巨大装饰球、粗阴影或嵌套底座。
- 圆角控制在 16–18 像素。

## 4. 核心能力

核心能力使用 GitHub 原生 Markdown 文本，不生成独立卡片。

建议结构：

```text
核心能力

嵌入式开发
C / C++ / STM32
设备通信、控制逻辑与嵌入式应用开发

实时系统
RTOS / 状态管理 / 任务调度
关注并发、事件、消息和长期可维护性

工具与应用
Flutter / Docker / AI Agent
构建个人工具、自托管服务与辅助开发工作流
```

规则：

- 每项能力为一个三级标题或加粗标题。
- 技术名放在一行短文本中。
- 描述最多一行。
- 不使用品牌色图标或徽章。
- 三项之间只靠留白和细分隔线区分。

## 5. 当前研究方向

当前研究方向使用 Linear Issue 风格的四行条目：

- 嵌入式软件架构
- RTOS
- 个人知识管理
- AI Agent 工作流

每行包含：

- 一个小圆点或状态符号
- 方向名称
- 一句短说明
- 可选状态文本，例如 `研究中` 或 `持续迭代`

规则：

- 不使用四张独立彩色卡片。
- 所有状态符号使用同一个紫蓝强调色。
- 每行之间使用极细分隔线。

## 6. 精简开发数据

开发数据只保留三个信息：

- 公开仓库数
- 贡献或提交总量
- 主要编程语言

显示方式：

- 使用一张明亮统计卡片和一张深色统计卡片，自动切换。
- 尺寸为一行横向数据，不再展示大型活动图、语言面积图或多张统计卡片。
- 统计卡片标题和字段使用中文。
- 背景、边框、字体和强调色与 Linear 横幅统一。

数据可继续由 GitHub Actions 自动生成或由现有统计 SVG 后处理获得，但最终只保留这一张精简卡片。

## 7. 贪吃蛇贡献轨迹

保留现有贡献贪吃蛇功能。

配色：

明亮主题：

- 空白方块：浅灰
- 贡献方块：灰紫到浅蓝紫
- 贪吃蛇：低饱和紫色

深色主题：

- 空白方块：深灰
- 贡献方块：深紫灰到蓝紫
- 贪吃蛇：较亮紫蓝色

规则：

- 保持透明背景。
- 不增加外部大卡片容器。
- 置于页面最后。
- 缩小上下留白，让它成为数据区的自然延伸。

## 10. 自动化

GitHub Actions 需要完成：

1. 生成明暗两张 Linear 横幅。
2. 生成或处理明暗两张精简统计卡片。
3. 生成明暗两张紫蓝色贡献贪吃蛇。
4. 验证 README 引用完整。
5. 验证 SVG 可解析。
6. 验证明暗资源成对存在。
7. 验证旧 Apple 页面资源不再被 README 引用。
8. 验证生成器连续运行两次结果一致。

## 11. 验收标准

- 页面只包含五个已确认模块。
- 顶部只有一张轻量横幅。
- README 中不再出现精选项目和最近动态。
- 核心能力与研究方向使用原生文本，不是大型 SVG 卡片。
- 只有一张精简开发数据卡片。
- 贪吃蛇保留并支持明暗主题。
- 明暗主题切换正确。
- 移动端没有横向溢出或过小文字。
- 页面整体看起来像一个克制的产品页面，而不是 GitHub 模板组件合集。
